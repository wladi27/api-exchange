Endpoints

GET /tipo-cambio 200 OK Recommended

Get both USD and EUR exchange rates in a single request.

Request
GET http://localhost:5001/api/v1/tipo-cambio
Response
{
  "success": true,
  "version": "v1",
  "date": "Lunes, 27 Julio 2026",
  "prices": {
    "usd_bs": 742.2292,
    "eur_bs": 844.21891437
  },
  "source": "Banco Central de Venezuela"
}
GET /dolar 200 OK

Get the current USD exchange rate.

Request
GET http://localhost:5001/api/v1/dolar
Response
{
  "success": true,
  "currency": "USD",
  "price_bs": 742.2292,
  "date": "Lunes, 27 Julio 2026"
}

GET /historico/dolar 200 OK

Get 30-day historical USD exchange rates.

Request
GET http://localhost:5001/api/v1/historico/dolar
Response
{
  "success": true,
  "historical": [
    {"date": "2026-07-27", "price": 742.22}
  ]
}

Debug endpoint showing all currencies found in the BCV HTML.

Response
{
  "currencies_by_id": {
    "dolar": 742.2292,

  }
}

Code Examples

JavaScript 
fetch('http://localhost:5001/api/v1/dolar')
  .then(res => res.json())
  .then(data => {
    console.log('USD:', data.price_bs);
  })
  .catch(error => {
    console.error('Error:', error);
  });
Python 
import requests

try:
    response = requests.get('http://localhost:5001/api/v1/dolar')
    data = response.json()
    print(f"USD: {data['price_bs']}")
except Exception as e:
    print(f"Error: {e}")
cURL 
curl -X GET \
  -H "Accept: application/json" \
  http://localhost:5001/api/v1/dolar
PHP 
<?php
$ch = curl_init('http://localhost:5001/api/v1/dolar');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
$data = json_decode($response, true);
echo "USD: " . $data['price_bs'];
curl_close($ch);
?>

Response Codes

200 OK

Request successful. Data returned correctly.

404 Not Found

Endpoint not found or data unavailable.

500 Error

Internal server error. Try again later.
